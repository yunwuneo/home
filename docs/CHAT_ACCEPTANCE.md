## 真实记忆链路

- 对话/记忆提取：`gpt-4o-mini`；向量化：`text-embedding-3-small`，实际返回 1536 维向量。
- 用户说喜欢茉莉花茶、不加糖 → 自动提取 → 新话题正确召回。
- 用户纠正为乌龙茶 → 更新旧事实 → 后续回答使用乌龙茶。
- 遗忘 → 删除向量，并排除旧事实相关上下文 → 后续回答明确没有记录。
- 记录周六下午在河畔书屋读书到五点 → Web 和原生 iOS 均能跨话题回答并展示来源。
- 临时邀请“今晚陪我拼一幅星空拼图吧。” → 真实提取结果为 0，未被错误推断为长期喜好。
- 服务端重启 → 配置、话题、聊天、记忆均恢复。密钥读取接口脱敏。
- 失败原子性、重复发送去重、模型变更后向量失效检查由服务端测试覆盖。

## 尚需外部条件的验证

1. 当前网关的模型列表没有明确的语音模型。实际调用 `whisper-1` 转写和 `tts-1` 合成都返回 HTTP 422；云端语音需配置可用服务商/模型后补验，不能视为已跑通。[请求状态记录](../artifacts/chat/voice-provider-results.json)
2. 模拟器不提供实体相机；已验证入口和无相机提示。实际拍照和麦克风采集/识别仍需真机验收。设备朗读已触发，但截图不能证明扬声器听感。
3. 未部署生产环境。验收服务在本机 5187 端口，使用独立数据；正常启动项目仍读取原存档。
